# Authentication & Authorization System

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

## Setup Instructions

1. Clone repository

2. Install dependencies

npm install

3. Add .env file

4. Run server

npm run dev

## API Endpoints

POST /api/auth/register

POST /api/auth/login

GET /api/auth/profile

PUT /api/auth/profile

GET /api/auth/users

DELETE /api/auth/users/:id
